FreeDot Linux

System Pipeline

A minimal Linux distribution and custom C++20 PID 1 init system built from scratch under strict resource constraints (≤ 600 MB memory footprint). Inspect the sequential low-level boot architecture and POSIX interfaces below.

Track on GitHub →
01

Stage 1: Firmware & Kernel Bootstrap

BIOS / UEFI → bzImage

Firmware initializes hardware and hands execution to the bootloader, loading the upstream Linux LTS kernel into RAM. The kernel unpacks the 3.9 MB compressed initramfs CPIO archive into an in-memory rootfs, initializes virtual drivers, and invokes userspace at /init.

bzImage LTS Kernel 3.9 MB cpio initramfs execve("/init") Handoff
02

Stage 2: PID 1 Supervisor Initialization

mount(2) • ioctl(2) • waitpid(2)

Kernel transfers control to /init as PID 1. The custom C++20 supervisor invokes mount(2) to mount essential virtual filesystems (/proc, /sys, /dev, /dev/pts, /run), brings up network interfaces (lo, eth0) via kernel socket ioctl(SIOCSIFADDR), and establishes asynchronous SIGCHLD zombie reaping via waitpid(-1, &status, WNOHANG).

mount("proc", "/proc") ioctl(SIOCSIFADDR) Bringup waitpid(WNOHANG) Reaping
03

Stage 3: Service Dependency Ordering & IPC

DAG Topological Sort • AF_UNIX

The init supervisor parses declarative unit manifests in /etc/freedot.d/*.conf, calculates safe startup order using directed acyclic graph (DAG) topological sorting to eliminate deadlocks, and opens a non-blocking UNIX domain socket (socket(AF_UNIX, SOCK_STREAM, 0)) bound to /run/freedot.sock before launching telemetry daemons (logger, statsd) with watchdog auto-restart.

DAG Topological Sort socket(AF_UNIX) IPC Daemon Auto-Restart
04

Stage 4: Userspace Execution & Interactive Console

/dev/console • freedotctl

Spawns an interactive BusyBox shell (/bin/sh) attached to /dev/console with raw TTY line discipline. Exposes the custom freedotctl CLI client communicating over /run/freedot.sock for real-time process queries, service restarts, and clean ACPI shutdown via sync() and reboot(RB_POWER_OFF).

/bin/sh on /dev/console freedotctl IPC Client reboot(RB_POWER_OFF)
